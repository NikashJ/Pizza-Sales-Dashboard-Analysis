# Pizza-Sales-Dashboard-Analysis
## Pizza sales analysis using Power Bi
# OVERVIEW
- The Pizza Sales Dashboard gives a clear and detailed overview of  pizza sales performance, helping us understand customer preferences and how sales are trending.
- It provides important information, like total revenue, the number of orders, the pizzas sold, and average order values. 
- Dashboard also examine sales by different pizza categories and sizes and track trends over time, both daily and monthly. 
- With its easy-to-read visuals and practical insights, this dashboard is an essential tool for monitoring the performance. 
- It helps us identify peak sales times and better understand what our customers love, ultimately guiding us to make smarter, data-driven business decisions.
- Navigations buttons are used to switch from one page to another.
- Pizza Sales Dashboard presenting key insights into sales trends using various charts and highlights.
- It examines the top and bottom performance of the pizza.

# Why cards?
- I have used cards in your Pizza Sales Dashboard to display key performance indicators (KPIs) that provide a quick, high-level overview of important business metrices. Here’s why they are essential.
  1)Instant Insights – Cards display key performance indicators (KPIs) like Total Revenue, Orders, Average Order Value (AOV), and Pizzas Sold, helping you quickly assess sales.
  2)Easy Comparisons – Track trends easily over time without getting lost in charts, simplifying your decision-making.
  3)Clear Visual Hierarchy – With key metrics upfront, you can focus on what's important before exploring details.
  4)Minimal Space, Maximum Value – These cards maximize limited dashboard space while delivering essential information.
- Cards help users identify patterns, track business performance, and make data-driven decisions without extra effort.

# Why Slicer ?
- A slicer makes it super easy for you to filter data in a report by different categories. It provides a clean and friendly interface that allows you to apply filters effortlessly. Plus, you can quickly select or deselect data points, giving you a more interactive experience as you explore your data.
- The Pizza Sales Dashboard features a slicer in the "Pizza Category" section, allowing users to filter data by, 
  1)Classic
  2)Supreme
  3)Chicken
  4)Veggie.
- Selecting a category updates all charts and metrics in real-time, enhancing interactivity and analysis.
